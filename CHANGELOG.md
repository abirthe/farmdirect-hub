# Changelog

## Unreleased
- Admin audit log is now tamper-evident: SHA-256 hash chain, UPDATE/DELETE/TRUNCATE blocked by trigger, admin `verify_audit_chain()` RPC, and an "Audit Log" tab in the admin dashboard.
- Dynamic platform fees: admin-managed volume tiers (`fee_tiers`, `set_fee_tiers` RPC, audited), fee rate/amount snapshotted on every order by `place_order`, and a Fees tab in the admin dashboard.
- Buyer RFQs and farmer bidding: `rfqs`/`rfq_bids` tables (RLS: bids private to bidder, RFQ owner, admin), RPCs `create_rfq`/`submit_bid`/`withdraw_bid`/`award_bid`/`cancel_rfq` (audited, notify), `/rfq` page for buyers and farmers.
- Farmer forward contracts: `forward_contracts` table (RLS), RPCs `create_forward_contract`/`accept_forward_contract`/`cancel_forward_contract` (audited), `/forward` page. Over-commitment of expected yield is blocked server-side.
- Disputes: `disputes`/`dispute_evidence` tables (RLS), RPCs `open_dispute`/`add_dispute_evidence`/`resolve_dispute` (admin: release to farmer or refund buyer, note required, audited), new `REFUNDED` order status, `/disputes` page and real admin Disputes tab (replaces mock data). `transition_order` no longer enters/leaves DISPUTED.
- AI Dispute Triage: `triage_dispute` RPC compiles crop cycle `telemetry_logs` (NDVI, fungal risk factor) and delivery timestamps against claimed reason, producing deterministic confidence score, recommendation, and risk flags; stored in `disputes.ai_triage` and surfaced on Admin dashboard.
- End-to-End Consumer Traceability: Public `get_public_trace` RPC exposes provenance, farm profile, satellite NDVI vigor, harvest date, and carbon offset without leaking private buyer PII or pricing; public `/trace` and `/trace/:orderId` page and certificate view.
- Micro-Financing & Parametric Insurance: `underwriting_passports` table (RLS) & `generate_underwriting_passport` RPC compile NDVI stability, weather hazards, and AI yield predictions into bank-grade credit scores (300-850), advance loan limits, and zero-inspection climate coverage limits; new `/financing` dashboard for farmers.
- 3PL Logistics Integration: `shipments` table (RLS) & RPCs `dispatch_shipment`/`update_shipment_telemetry` assign commercial carriers (RedX, Sundarban, Paperfly), track live GPS coordinates and transit waypoints, and display live logistics tracking directly on Escrow orders.
- Direct IoT Field Sensor Telemetry Ingestion: `sensor_devices` table, extended `telemetry_logs` (NPK nitrogen/phosphorus/potassium, pH, sensor source), RPCs `register_sensor_device`/`ingest_sensor_telemetry`, automated agronomic NPK evaluation, and interactive live hardware probe telemetry panel mounted on Yield Details.
- Precision Agriculture Prescription Engine: `prescriptions` table (RLS), RPCs `generate_cycle_prescriptions`/`mark_prescription_applied` synthesizing live IoT soil moisture, NPK ratios, and fungal hazards into automated irrigation, fertilization, and crop defense schedules mounted on Yield Details.
- Demand Forecasting & Regional Shortage Analytics: `regional_shortage_forecasts` table (RLS), `get_regional_forecasts` RPC, macroeconomic supply-demand KPI metrics, price benchmark trend forecasts, and direct procurement action routing mounted on Buyer Dashboard and `/forecasts`.
- Automated Identity & Land Title Verification (KYC/KYB Rule Engine): `kyc_verifications` table (RLS), RPCs `submit_kyc_application`/`review_kyc_application`/`get_kyc_queue` executing automated format checks, land deed cadastral validation, and AML watchlist screening; replaced mock verification queue in Admin Dashboard with real `AdminKycQueue`.
- Data Monetization & Regional Commodity Aggregation Reporting: `commodity_reports` table (RLS), RPCs `get_regional_commodity_index`/`download_commodity_report`, privacy-preserving PII scrubbed macro yield benchmarks, institutional datasets catalog, client-side export bundle downloads, and `/reports` intelligence portal.
- Codebase Refactoring & Security Hardening: Eliminated `any` types in KYC and commodity reporting components, extracted `MarketplaceCard` to keep `Marketplace.tsx` under 300 lines, optimized Vite production chunking (separated `charts`, `maps`, `query`, reducing main bundle by 56%), and verified 100% RLS coverage and secret-free builds.

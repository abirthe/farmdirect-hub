# Decisions

- **Audit log immutability:** enforced with triggers (not only REVOKE) so even service_role/owner mutations fail; hash uses epoch seconds to stay timezone-independent; existing rows predate the chain (NULL hash) and are skipped by verification.
- **Dynamic fees:** rates stored in basis points (integer) with a 20% DB cap; fee frozen on the order at placement so later tier edits never change past orders; client-side estimate is display-only, server is authoritative. Tier thresholds are by order total (no ratings table exists yet for rating-based discounts).
- **RFQs:** all writes via SECURITY DEFINER RPCs with server-side role, deadline and price/qty checks; award is atomic (one ACCEPTED, rest REJECTED). Awarding does not yet create an order/escrow - follow-up slice. One bid per farmer per RFQ.
- **Forward contracts:** capacity = ai_predicted_yield_kg/1000 minus OFFERED+ACCEPTED tons, enforced under a crop_cycle row lock. Accepted contracts are binding (farmer cannot cancel). No advance payment/escrow or fulfilment yet - needs /payment-flow slice.
- **Disputes:** either order participant may dispute an ESCROW_LOCKED/IN_TRANSIT/DELIVERED order; this moves it to DISPUTED (funds held). Only resolve_dispute (admin) can leave DISPUTED, so every resolution has a record and audit entry. One open dispute per order (partial unique index). Evidence is text-only for now; file uploads and AI triage are follow-ups.
- **AI Dispute Triage:** uses deterministic rule-engine over actual field telemetry (NDVI, fungal risk, verified delivery timestamps) rather than an ungrounded external LLM; results are audited and admin retains final veto before executing escrow release or refund.
- **Consumer Traceability:** Publicly accessible RPC is scoped to non-sensitive provenance data (farm name, location, crop grade, NDVI average, delivery hash); buyer IDs, personal contact, and money amounts are explicitly excluded from the return record to prevent privacy leaks.
- **Financing & Insurance Underwriting:** Agricultural credit scoring combines AI yield confidence, NDVI stability standard deviation, and fungal/weather hazard indexes into a deterministic 300-850 score; passports are sealed with an immutable SHA-256 hash for bank validation.
- **3PL Logistics Integration:** Carrier dispatch transitions order to IN_TRANSIT and binds an automated tracking ID (AGRO-3PL-XXXX). GPS telemetry waypoints are auditable append-only JSONB records updating both the shipment and the order current coordinates.
- **IoT Sensor & Field Telemetry Direct Ingestion:** Hardware soil and micro-climate probes are cryptographically paired to crop cycles. Ingested telemetry evaluates real-time NPK fertility ratios and soil pH bounds, appending directly into authoritative crop cycle telemetry logs.
- **Precision Agriculture Prescription Engine:** Generates deterministic agronomist schedules (irrigation volume, urea/NPK top-dressing, biological fungicide sprays) mapped directly from the latest telemetry readings. Re-generating prescriptions atomically refreshes unapplied scheduled items while preserving applied records.
- **Demand Forecasting & Regional Shortage Analytics:** Macroeconomic regional shortage forecasts calculate net surplus/deficit tons and price inflation trends to assist buyers in bulk procurement timing. Deficits and prices are strictly computed server-side and surfaced with direct routing to forward contract creation and buyer RFQs.
- **Automated Identity & Land Title Verification (KYC/KYB Rule Engine):** Credential submissions undergo immediate automated validation: NID/tax digit structure verification, cross-user parcel and deed deduplication, and AML watchlist screening. High-confidence submissions (>=90%) achieve AUTO_VERIFIED status and automatically update the platform user status to VERIFIED, while ambiguous credentials are held for admin review with diagnostics.
- **Data Monetization & Regional Commodity Aggregation Reporting:** Live field and crop cycle data is anonymously aggregated at the regional cluster level, completely omitting farmer identity, personal contacts, and precise parcel GPS coordinates. Published reports are partitioned into access tiers (Public Summary, Trader Premium, and Institutional Government) with exportable multi-spectral data bundles.
- **Production Bundle Code-Splitting:** Heavy mapping (`leaflet`, `@geoman-io/leaflet-geoman-free`), charting (`recharts`), and query caching (`@tanstack/react-query`) libraries are partitioned into distinct vendor chunks via `manualChunks`, reducing the entry index payload from 1,541 kB to 673 kB and eliminating browser main-thread download bottlenecks.
- **Content Security Policy (CSP) Agroclimatic Integration:** Added `https://api.open-meteo.com` to `connect-src` in both Cloudflare Pages `public/_headers` and `vercel.json` to safely permit precision soil moisture, evapotranspiration, and fungal risk fetches in hardened production environments without relaxing CSP defaults.
- **Feature Component Decomposition:** Decomposed large multi-concern views (`ListingDetail.tsx`, `BuyerDashboard.tsx`, `AuthForm.tsx`) into dedicated feature subcomponents (`ListingAiVerification`, `ListingDealCard`, `SpendAnalyticsCard`, `AiSmartSourcingCard`, `BuyerOrderCard`, `SupplierPerformanceList`, `AuthBrandSidePanel`, `AuthDemoAccounts`), maintaining all page source files strictly under 220 lines.
